# Lead time gained by watching the upstream gauge

_Generated by `eval/run_leadtime.py` from `eval/results/leadtime.json` (2026-10-25T11:19:14+00:00). Do not edit numbers by hand. Label: **REAL USGS gauge pairs, held-out 2024–2026 events**._

## What is measured

The agent's alert rule (Kalman-filtered stage from `jalrekha.vision.temporal.filter_series`, warning reached or rise ≥ 0.3 m/h projected to cross warning within 1.5 h) is run causally on 15-min gauge readings. **Baseline (downstream-only):** the rule on the downstream gauge. **Ours (combined):** the downstream rule plus the same rule on the upstream gauge against the upstream's own warning level; an upstream alert counts for a downstream event when it starts within W before the downstream crossing (W = 3 × TRAIN median travel time, at most 48 h). Gain = baseline alert time − combined alert time.

- Data: USGS NWIS instantaneous gauge height (00065), U.S. public domain, credit U.S. Geological Survey; NWS action stages from NOAA NWPS where the datum check passed. U.S. rivers, not Nepal/India.
- TRAIN 2021-01-01 – 2023-12-31 (thresholds, travel times); TEST 2024-01-01 – 2026-10-01 (held out).
- Warning level: **nws_action** (primary). Config `eval/config.leadtime.frozen.json` frozen 2026-10-25T11:12:40+00:00, sha256 `ff20cf6597603da3…`.
- Event: downstream raw stage crosses warning from below, stays >= warning for 2 readings, and was below warning for the previous 24 h.
- False alert: an upstream alert episode is false if the downstream raw stage does not reach its warning level within W after the episode onset; a downstream-only episode is false if it does not reach warning within 6 h.

## Notes and limits

- U.S. rivers with dense gauge networks; Nepal/India travel times, flashiness and data gaps differ. This shows the mechanism, not field performance there.
- `nws_action` uses the official NWS action stage of each gauge (NOAA NWPS; datum checked against the live USGS reading). `p95` uses the 95th percentile of TRAIN stage: a statistical level, so its events are high-water rises, mostly not damaging floods.
- The downstream-only time is the first rule firing in the run-up window (generous to the baseline); the upstream time is the onset of an upstream alert episode inside W (strict for ours).
- The Kalman filter runs at every reading (no skipping). Share of steps with filtered rate ≥ 0.3 m/h: gauge readings median 0.03%, with 5 cm camera noise median 8.37% (the filter's process noise lets the rate follow fast changes, so noisy readings also produce noisy rates).
- Runtime 172.3 s. Reproduce: `cd backend && uv run python ../eval/fetch_hydro_pairs.py && uv run python ../eval/run_leadtime.py`.
